## 🚀 How to Run Locally

### Option 1: Direct Double Click
Simply double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Opera, etc.).

### Option 2: Using VS Code Live Server
1. Open the `divya-portfolio` folder in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"**.

### Option 3: Using Node / npx
```bash
npx serve .
```

## 🌐 Deploying to GitHub Pages or Vercel
1. Push this folder to a GitHub repository named `divya-portfolio` or `<your-username>.github.io`.
2. On GitHub, go to **Settings > Pages > Branch: main / Root** and click **Save**.
3. Your live portfolio will be available worldwide!
